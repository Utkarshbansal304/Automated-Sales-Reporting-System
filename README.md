# 📊 Automated Sales Reporting System

## Overview
A Python-based automated reporting system that reads raw sales data,
performs data cleaning, KPI analysis, and generates a formatted Excel
report with embedded charts.

## Dataset
Superstore Sales Dataset — 9,800 rows, 18 columns

## KPIs Calculated
- Total Sales: $2,261,536
- Total Orders: 4,922
- Average Sale: $230.77
- Sales by Region, Category, Year, Month

## Tech Stack
- Python
- Pandas
- Matplotlib
- OpenPyXL

## How to Run
1. Clone the repo
2. pip install pandas matplotlib openpyxl
3. Run report_generator.ipynb in Jupyter
